# إصلاحات التشغيل

أُصلحت المشكلات الثماني التي حُددت في مراجعة النسخة المرفوعة:

- دمج الفواتير يمرر معرّف الشركة عند توليد رقم الفاتورة، ويحافظ على الساعات والأسعار عند التقسيم. يرفض التقسيم غير المطابق بدل الدخول في حلقة لا تنتهي.
- أُضيف أمر لإنشاء أول مدير للنظام بكلمة مرور يختارها المشغّل، مع استمرار إغلاق التسجيل العام افتراضيًا.
- تصدير PDF وWord يستخدم ملف الشركة المالكة للفاتورة. أُضيفت حقول البنك وIBAN وBIC والرقم الضريبي إلى إعداد الشركة، مع ترقية تحفظ البيانات الحالية.
- محادثة AI Intake تقبل إعداد OpenRouter دون مفتاح Gemini.
- صورة Docker تثبّت خطوط DejaVu، ويبحث مولّد العرض العربي عن خطوط Linux أيضًا. أُصلح ظهور وسم سطر جديد في عنوان العرض.
- بيانات العرض التجريبي لا تُنشأ إلا عند تفعيلها صراحة، ولا تستبدل بيانات الشركات أو الحسابات الموجودة.
- أُضيفت قوالب متغيرات البيئة الثلاثة المفقودة، وعُدّل تجاهل Git للسماح بحفظ القوالب المنقّحة.
- اختبار المتصفح يستخدم قاعدة اختبار مستقلة وكلمة مرور مطابقة للشروط وجلسة دخول عبر ملفات الارتباط.

## التشغيل لأول مرة

اتبع README لتثبيت المتطلبات وتشغيل التطبيق. بعد تشغيل Docker، أنشئ أول مدير بهذا الأمر من مجلد المشروع:

```powershell
docker compose exec backend python -m app.bootstrap --email admin@example.com
```

استبدل البريد ببريدك. سيطلب الأمر كلمة مرور لا تقل عن 12 حرفًا وتحتوي أحرفًا كبيرة وصغيرة ورقمًا ورمزًا خاصًا. لا تُحفظ كلمة المرور في سجل الأوامر. للتشغيل المحلي، نفّذ الأمر التالي من `backend-python` بعد تفعيل البيئة الافتراضية:

```powershell
python -m app.bootstrap --email admin@example.com
```

سجّل دخول المدير، وأنشئ شركتك من لوحة إدارة المنصة، ثم ادخل بحساب مدير الشركة وأكمل بيانات الشركة والبنك في إعداد الشركة. لن تُصدّر الفاتورة قبل اكتمال البيانات الأساسية للشركة.

## قاعدة بيانات موجودة

احتفظ بنسخة احتياطية قبل تحديث تطبيق يستخدم بيانات فعلية. في التشغيل المحلي يمكن تطبيق الترقية من `backend-python`:

```powershell
python -m alembic upgrade head
```

تشغيل Docker يطبق الترقية تلقائيًا قبل بدء الخدمة. الحقول الجديدة اختيارية ولا تستبدل بيانات الشركة الحالية. لا تحتاج إلى حذف قاعدة البيانات أو وحدات التخزين.

## حدود التحقق

تم تحديث الإعداد الافتراضي وقوالب البيئة وملفات Docker إلى `gemini-3.5-flash`. إذا كان لديك ملف `.env` سابق، حدّث قيمة `GEMINI_MODEL` فيه أيضًا، ثم أعد إنشاء حاوية الخلفية باستخدام `docker compose up -d --force-recreate backend` لتحميل القيمة الجديدة. لا يتطلب تغيير اسم النموذج تثبيت تبعيات إضافية. تم التحقق من تمرير المعرّف إلى عميل Gemini دون إجراء طلب إلى الخدمة الحية.

توجد اختبارات جديدة لدمج الفواتير، وإنشاء أول مدير، وفصل بيانات الشركات في التصدير، وOpenRouter، وحماية البيانات التجريبية، وإضافة حقول الدفع إلى ملف شركة قديم. يجب اختبار PostgreSQL وصورة Docker وخدمات الذكاء الاصطناعي بمفاتيحك في بيئة النشر؛ لم يتوفر محرك Docker أثناء تنفيذ الإصلاحات.
